# 🏥 Primary Health Centre – Clinic Management System

## 📌 Overview

The Primary Health Centre – Clinic Management System is a secure healthcare management platform developed to streamline clinic operations and improve patient management.

This project was developed as part of a Bachelor of Information Technology capstone project.

---

## 🚀 Features

* Patient Registration
* Appointment Scheduling
* Reception Management
* Check-in / Check-out Logging
* Role-Based Access Control (RBAC)
* Notifications & Alerts
* Audit Logging
* Secure Authentication
* Healthcare Data Security

---

## 🛠 Technologies Used

* PHP
* MySQL
* HTML
* CSS
* JavaScript
* XAMPP
* Cisco Networking Concepts
